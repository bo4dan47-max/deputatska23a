# Збір коштів · Депутатська 23а

Статичний сайт + Netlify Function, яка зберігає внески в Netlify Blobs.
Пароль адміна лежить тільки на сервері (змінна середовища), у коді сайту його немає.

## Запуск
1. Створіть репозиторій на GitHub і завантажте всі файли цієї папки (зі збереженням структури).
2. На netlify.com: **Add new site → Import an existing project** → оберіть цей репозиторій. Налаштування збірки підтягнуться з `netlify.toml`.
3. До першого деплою (або після нього з повторним деплоєм) відкрийте **Site configuration → Environment variables** і додайте:
   `ADMIN_PASSWORD` = `2332` (або будь-який інший пароль).
4. Задеплойте сайт (Deploys → Trigger deploy). Готово.

## Як вносити
Кнопка «Вхід для адміна» вгорі справа → пароль → номер квартири та сума → «Зберегти».
Внесок додається до наявного; галочка «замінити суму» виправляє помилку.

## Зміна параметрів
- Кількість квартир / поверхи: `SECS` у `public/index.html` і `TOTAL_APTS` у `netlify/functions/payments.mjs`.
- Ціль збору та внесок з квартири: об’єкт `state` у `public/index.html` (`goal`, `per`).
- Пароль: змінна `ADMIN_PASSWORD` в Netlify, потім повторний деплой.
